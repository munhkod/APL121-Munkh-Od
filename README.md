# APL121 · Бие даалт №1 — Code Quest

**Сэдэв №4: Цахилгааны төлбөр**

Гэр бүлийн гишүүдийн тоо, нэг хүний сарын дундаж хэрэглээ, ахмад настан байгаа эсэхийг оруулахад
программ 12 сарын хэрэглээг улирлаар тооцоолж, шатлалтай тарифаар сар бүрийн төлбөрийг хүснэгтээр
хэвлэнэ. Мөн хамгийн их зарцуулсан сарыг олж, хэмнэлтийн зөвлөмж өгнө.

## Ажиллуулах

```bash
gcc main.c -o main
./main
```

Flowgorithm: `quest.fprg` файлыг нээгээд **Run** дарна.

## Өөрийн тогтоосон дүрмүүд

> Тоонууд нь энэ даалгаварт зориулж би өөрөө тогтоосон, албан ёсны тариф биш.

**1. Шатлалтай тариф** (шатлал бүрийн хэсгийг өөрийн үнээр тооцно):

| Шатлал | Хэрэглээ | 1 кВт.ц-ийн үнэ |
|--------|----------|-----------------|
| 1 — Хэмнэлт | 0 – 150 кВт.ц | 150₮ |
| 2 — Дундаж | 150.01 – 300 кВт.ц | 200₮ |
| 3 — Өндөр | 300-аас дээш | 280₮ |

**2. Суурь хураамж:** сар бүр 2000₮ нэмнэ.

**3. Ахмад настны хөнгөлөлт:** гэрт ахмад настан байгаа **БӨГӨӨД** тухайн сарын хэрэглээ ≤ 200 кВт.ц бол
төлбөрөөс (хураамжийн хамт) 10% хасна.

**4. Улирлын коэффициент:** сарын хэрэглээ = гишүүд × нэг хүний хэрэглээ × коэффициент.
Монголын өвөл урт, харанхуй тул өвлийн саруудад хэрэглээ өндөр байна.

| Сар | 12, 1 | 2 | 11 | 3, 10 | 4, 9 | 5, 8 | 6, 7 |
|-----|-------|---|----|-------|------|------|------|
| Коэф. | 1.5 | 1.4 | 1.3 | 1.2 | 1.0 | 0.8 | 0.7 |

**5. Оролтын хязгаар:** гишүүд 1–20, нэг хүний хэрэглээ 0 < x ≤ 500 кВт.ц, ахмад настан 0 эсвэл 1.
Буруу утга орвол do-while-аар дахин асууна.

**6. Хамгийн их сар:** хоёр сар тэнцүү бол эхнийх нь сонгогдоно.

## Заавал байх 7 элемент хаана байгаа вэ

| № | Элемент | Хаана |
|---|---------|-------|
| 1 | Оролт/гаралт | 3 `scanf` (гишүүд, хэрэглээ, ахмад настан), `printf` хүснэгт |

| 7 | Оролтын шалгалт | 3 `do-while` |
